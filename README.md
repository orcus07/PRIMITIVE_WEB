# 📰 영문 링크 → 한글 증류 리더

영어 장문 자료의 링크를 던지면, **원문 의도에 충실하게 한글로 번역·구조화하고 핵심을 증류**해
바로 읽을 수 있는 자료로 만들어 줍니다. 기본 관점은 인증된 개인 서재에서 가져옵니다.
원문 번역·구조화와 독자 관점의 해석을 구분하며, 직접 수정한 관점은 자동으로 덮어쓰지 않습니다.

## 어떻게 동작하나

```
영문 링크 → 본문 수집(3중 전략) → Claude가 한글로 번역·구조화·증류 → 읽을거리 + 보관함 저장
```

**본문 수집 전략** (봇 차단 사이트 대응):
1. 브라우저처럼 직접 요청
2. 막히면 리더 프록시(`r.jina.ai`) 우회
3. 그래도 막히면 → 화면에서 **본문 직접 붙여넣기**

**결과물**:
- 한 줄 핵심 (증류)
- 이 글의 주제·맥락
- 📌 독자 관점의 해석 (원문과 구분)
- 원문 흐름을 따른 충실한 한글 본문 정리 (요약 아님)
- 핵심 용어·숫자 풀이
- → 보관함에 저장되고 검색 가능

요약·번역 엔진: **Claude `claude-opus-4-8`**

## 준비물

1. **Node.js 20 이상** — https://nodejs.org
2. **API 키 1개**: `ANTHROPIC_API_KEY` — https://console.anthropic.com

> OpenAI 키는 필요 없습니다(이전 버전과 달라진 점).

## 실행 방법

```bash
npm install
cp .env.example .env      # ANTHROPIC_API_KEY 입력
npm start                 # http://localhost:3000
```

## 클라우드 배포 (폰·PC 어디서나 쓰기)

노트북을 켜둘 필요 없이 항상 떠 있는 주소를 만들려면 → [`DEPLOY.md`](DEPLOY.md) (Render 무료 배포, 클릭 위주 안내).

## 사용법

1. 상단에 영문 아티클 링크를 붙여넣고 **증류**(또는 Enter)
2. 잠시 후 한글 정리 결과가 표시되고 왼쪽 보관함에 저장됨
3. 링크가 봇 차단으로 막히면 → "본문 직접 붙여넣기"로 원문을 붙여넣어 처리
4. 보관함에서 검색하거나 지난 글을 다시 열어볼 수 있음

## 파일 구성

```
src/server.js           서버 (링크 → 수집 → 증류)
src/lib/fetchArticle.js 본문 수집 (직접 요청 → 프록시 우회)
src/lib/distill.js      Claude 번역·구조화·증류 (페르소나 반영)
public/                 화면(UI) + 보관함
```

## 참고 / 한계

- 일부 사이트(예: Cloudflare 보호)는 직접/프록시 모두 막힐 수 있어요 → 본문 붙여넣기로 우회
- 매우 긴 글은 출력 한도(16K 토큰)로 일부 잘릴 수 있습니다
- 보관함 데이터는 사용하는 브라우저(localStorage)에만 저장됩니다

## 완성도와 관점 설정

실사용 서비스는 `https://meeting-notes-eu0u.onrender.com`이며 배포 브랜치는 `claude/unclear-request-plepdz`입니다.

- JSON 파싱과 내용 검사를 구분합니다. 중단·원문 누락 등의 복합 신호가 있으면 검토 초안으로 보관하며 기존 정상 자료를 덮어쓰거나 PC로 자동 전송하지 않습니다. 단일 신호는 경고일 수 있습니다. 자동 검사는 의미의 완전성을 보증하지 않습니다.
- 초안의 의심 구간만 원문과 대조해 편집·저장할 수 있습니다. 전체 증류는 자동 재호출하지 않습니다. 별도 유료 구간 재생성 기능은 없습니다.
- 직접 접속도 서재 취향이 기본입니다. 인증된 PC 연결에서 가져온 관점만 사용하고, 연결 불가 시 마지막 저장 시각과 오프라인 상태를 표시합니다. 캐시도 없으면 연결 또는 직접 입력이 필요합니다.
- 관점은 증류 전에 읽고 수정할 수 있습니다. 서재 작업도 시작 버튼을 눌러 실행합니다. 수동 관점은 유지하고, 서재 취향으로 되돌리기를 제공합니다.
- 결과 자동 회수는 계속 서재에서 시작한 작업에만 적용합니다. PC의 교정 버전은 구버전 브라우저 본문으로 덮어쓰지 않습니다.
- 개인 취향·대화·인증값·복구 대상 원문은 공개 저장소에 넣지 않습니다.

검증: `node --test test/quality.test.js`. 브라우저 회귀 검사는 `PLAYWRIGHT_MODULE`에 기존 Playwright 설치 경로를 지정한 뒤 `node test/reader-browser.cjs`로 실행합니다. 모든 요청을 가로채므로 모델 호출이나 운영 데이터 변경은 없습니다.
